## Source and scope

These are the five files supplied for review on 1 October 2026, identifying the project as `23_Selection`. They are a supplied snapshot, not a claim to reproduce a particular current SDK release. The build-file notice says 2025; that is not an SDK version number. No exact SDK build, Qt version, parent CMake project, or resource assets accompanied the files.

The listings preserve the supplied code, comments, notices, disabled sections, and existing quirks. Only the `LICENSEKEY` and `LICENSESIG` string values in `main.cpp` have been replaced with publication placeholders, and line endings and trailing whitespace are normalized. The C++ sample has not been compiled or run for these articles.

**Files**

- [`main.cpp`](#maincpp) — application construction and signal wiring.
- [`selection.h`](#selectionh) — declarations and inline setters.
- [`selection.cpp`](#selectioncpp) — scene loading, readout, cursors, and optional examples.
- [`selection.qrc`](#selectionqrc) — embedded resource manifest.
- [`CMakeLists.txt`](#cmakeliststxt) — target definition inside the SDK build.

## Build context

The CMake target depends on definitions outside this directory, including `vsn_qt_wrap_cpp`, `vsn_qt_add_resources`, `vsn_link_with_qt_vislib_math`, `QtVision_OUTPUT`, `23_Selection_OUTPUT`, and `SRC_Shared`. The included framework and kernel headers likewise come from the SDK. Do not expect configuring this directory by itself to resolve those dependencies.

To reproduce the example, start from a compatible SDK's documented parent build and toolchain, use its example target configuration, supply the eleven files named by `selection.qrc`, and configure your own license values locally. The `.qrc` includes the sample `.c3d` model, filter icons, and cursor images; a manifest is not a substitute for those files.

Record the SDK build, Qt version, compiler, platform, and resource source when making a reproducible application project. A successful website build checks the article formatting, not the validity of this C++ target against an SDK.

## Active code and optional sketches

The active path constructs a window, enables selection actions, opens the bundled model, builds scene geometry, changes display settings, and mirrors selected-item identifiers into a table. Other code needs to be read with its compile-time switches and call sites in mind:

| Code | State in these files | What would be needed to use it |
| --- | --- | --- |
| `FIND_TOPOLOGYBYHASH` | Disabled; lookup refers to undeclared `m_pModel` | Connect to the current kernel model, validate owner type and identifiers, handle failed/ambiguous resolution |
| `OTHER_METHOD_1` | Disabled; `m_pFindArea` is never assigned | Obtain the intended area process and connect its start callback before using the veto |
| `OTHER_METHOD_2` | Disabled; no activation action or finish connection is supplied | Provide process access, activation action, finish connection, and initial enabled-state policy |
| `LINE_SEGMENT` | Disabled; helper has no call site here | Decide when to create the extra scene segment and how to manage its lifetime |
| `_selectSegment` | Defined but not called here | Call it for its intended grouping-node case, or deliberately generalize its traversal |
| `SetPickingByGeometry` | Commented out in `main.cpp` | Inspect the installed SDK's contract before changing the picking path |

The existence of unfinished custom area handlers does not imply that the area tool enabled through `ModelEditor::Area` is itself disabled or broken. These are separate paths.

## Details worth noticing while reading

The output widget assigns widths to columns 0 and 1 again while setting up the headers for columns 3 and 4. This looks like a copy-and-paste error; it is retained so the listing remains faithful. `main.cpp` also removes the selection-color alpha subproperty twice. Neither detail is an architectural requirement.

The topology sketch uses an unchecked cast to `MbSolid` and accepts the first matching name hash. Its assertion is a debugging check, not a user-facing policy for missing references. Part 2 proposes explicit checks without presenting them as code already implemented here.

The table sets its row count from the entire selection collection but fills rows only for successful `InstSelectionItem` casts. If other item kinds occur, unused rows can remain. The source also blocks signals per row after clearing and resizing the table; that is not a complete guard for a future editable, bidirectional readout.

The helper is parented to the scene widget by Qt. The generator is explicitly deleted in its completion callback. The assertion in the helper destructor checks that no generator remains; it does not implement cancellation. Shutdown and overlapping loads require the surrounding framework's lifecycle contract to be understood.

These observations distinguish the sample's teaching value from the additional decisions needed for an application. The listings below intentionally do not silently repair them.

static SceneSegment* CreateLineSegment(SceneSegment* pTopSegment)
{
    Q_ASSERT(pTopSegment != nullptr);

    pSketch->AddSegment(new MbLineSegment(MbCartPoint(0.0, 0.0), MbCartPoint(0.0, 50.0)));

#define FIND_TOPOLOGYBYHASH 0
#if FIND_TOPOLOGYBYHASH
static MbTopologyItem* findTopologyByHash(const MbSolid* solid, uint32 primitiveId, ObjectType typeObject)
{
    RPArray<MbTopologyItem> items;
    switch (typeObject)
    {
        case ObjectType::Face:
        {
            solid->GetFaces(items);
            break;
        }
        case ObjectType::Edge:
        {
            RPArray<MbCurveEdge> edges;
            solid->GetEdges(edges);
            std::copy(edges.begin(), edges.end(), std::back_inserter(items));
            break;
        }
        case ObjectType::Vertex:
        {
            RPArray<MbVertex> vertexes;
            solid->GetVertices(vertexes);
            std::copy(vertexes.begin(), vertexes.end(), std::back_inserter(items));
            break;
        }
    }
    for (MbTopologyItem* curItem : items)
    {
        if (curItem->GetName().Hash() == primitiveId)
            return curItem;
    }
    return nullptr;
}
#endif

static QString typePrimitive(InstSelectionItem* item)
{
    QString strText("N");
    switch (item->GetType())
    {
        case ObjectType::Vertex: strText = QString("Vertex"); break;
        case ObjectType::Edge: strText = QString("Edge"); break;
        case ObjectType::Face: strText = QString("Face"); break;
    }
    return strText;
}

/* _selectSegment */
static void _selectSegment(SelectionManagerPtr ptrSelectManager, SceneSegment* pSegment)
{
    if (pSegment->GetRepresentation() == nullptr)
    {
        auto listItem = pSegment->GetChildSegments();
        for (auto it = listItem.begin(); it != listItem.end(); ++it)
        {
            SceneSegment* pSegmentItem = (*it);
            if (pSegmentItem->GetRepresentation() == nullptr)
                _selectSegment(ptrSelectManager, pSegmentItem);
            else
                ptrSelectManager->Select(pSegmentItem->GetUniqueKey());
        }
    }
}

void Selection::slotOpenModel(MxModelExtension* model)
{
    if (model == nullptr)
        return;

    if (m_pSegModel != nullptr)
    {
        SceneSegment* pTopSegment = m_sceneWidget->sceneContent()->GetRootSegment();
        Q_ASSERT(pTopSegment != nullptr);
        pTopSegment->RemoveSegment(m_pSegModel);
    }

    SceneSegment* pTopSegment = m_sceneWidget->sceneContent()->GetRootSegment();
    Q_ASSERT(pTopSegment != nullptr);
    m_pSceneGenerator = new SceneGenerator();
    ProgressBuild* pProgressBuild = m_pSceneGenerator->CreateProgressBuild();
    Object::Connect(m_pSceneGenerator, &SceneGenerator::SetupIDMapping, m_sceneWidget->modelEditor(),
        &ModelEditor::slotSetupIDMapping);
    Object::Connect(pProgressBuild, &ProgressBuild::BuildAllCompleted, this,
        [this]()
        {
            VSN_DELETE_AND_NULL(m_pSceneGenerator);
            m_sceneWidget->viewport()->ZoomToFit(m_sceneWidget->sceneContent()->GetBoundingBox(), 1.5f);
            m_sceneWidget->update();
        });

    m_pSegModel = m_pSceneGenerator->CreateSceneSegment(model, pTopSegment);
    m_pSceneGenerator->StartBuildGeometry();
}

void Selection::slotItemSelectModified()
{
    Q_ASSERT(m_ptrSelectManager != nullptr);
    QFontMetrics fm(m_outputTable->font());
    const int height = fm.boundingRect("X").height() + fm.boundingRect("X").height() / 2;

    auto& lstItem = m_ptrSelectManager->GetSelectionItems();

    m_outputTable->clearContents();
    m_outputTable->setRowCount(static_cast<int>(lstItem.size()));
    int index = 0;
    for (auto it : lstItem)
    {
        if (InstSelectionItem* item = dynamic_cast<InstSelectionItem*>(it))
        {
            MbPath path = item->GetMathPath();
#if FIND_TOPOLOGYBYHASH
            MbMatrix3D mx;
            const MbItem* pMathItem = m_pModel->GetItemByPath(path, mx);
            if (pMathItem != nullptr)
            {
                const MbSolid* pSolid = static_cast<const MbSolid*>(pMathItem);
                uint32 id = item->GetMathPrimitive();
                if (id != c3d::UNDEFINED_SNAME)
                {
                    MbTopologyItem* pTopologyItem = findTopologyByHash(pSolid, item->GetMathPrimitive(), item->GetType());
                    pTopologyItem = pTopologyItem;
                    Q_ASSERT(pTopologyItem != nullptr);
                }
            }
#endif
            bool bBlocked = m_outputTable->blockSignals(true);
            String strKey = item->GetNodeKey().ToString();
            m_outputTable->setItem(index, 0, new QTableWidgetItem(strKey.c_str()));
            m_outputTable->item(index, 0)->setTextAlignment(Qt::AlignRight | Qt::AlignVCenter);
            m_outputTable->setItem(index, 1, new QTableWidgetItem(QString::number(item->GetIndexBody())));
            m_outputTable->item(index, 1)->setTextAlignment(Qt::AlignRight | Qt::AlignVCenter);
            m_outputTable->setItem(index, 2, new QTableWidgetItem(QString::number(item->GetPrimitiveId())));
            m_outputTable->item(index, 2)->setTextAlignment(Qt::AlignRight | Qt::AlignVCenter);
            m_outputTable->setVerticalHeaderItem(index, new QTableWidgetItem(typePrimitive(item)));
            m_outputTable->setRowHeight(index, height);

            if (path.Count() > 0)
            {
                m_outputTable->setItem(index, 3, new QTableWidgetItem(QString::number(item->GetMathPath().Hash())));
                m_outputTable->item(index, 3)->setTextAlignment(Qt::AlignRight | Qt::AlignVCenter);
                m_outputTable->setItem(index, 4, new QTableWidgetItem(QString::number(item->GetMathPrimitive())));
                m_outputTable->item(index, 4)->setTextAlignment(Qt::AlignRight | Qt::AlignVCenter);
                m_outputTable->setVerticalHeaderItem(index, new QTableWidgetItem(typePrimitive(item)));
                m_outputTable->setRowHeight(index, height);
            }

            m_outputTable->blockSignals(bBlocked);
            index++;
        }
    }
}

// ---
bool Selection::eventFilter(QObject* watched, QEvent* event)
{
    if (watched != m_sceneWidget)
        return QObject::eventFilter(watched, event);

    if (event->type() == QEvent::MouseMove)
    {
        QCursor curCursor;
        ObjectType type = ObjectType::None;
        if (SelectionItem* item = m_ptrSelectManager->GetHighlightItem())
            type = item->GetType();

        switch (type)
        {
            case ObjectType::Vertex: curCursor = m_curVertex;
                break;
            case ObjectType::Edge: curCursor = m_curEdge;
                break;
            case ObjectType::Face: curCursor = m_curFace;
                break;
            default: curCursor = m_curPoint;
                break;
        }
        m_sceneWidget->setCursor(curCursor);
    }
    return QObject::eventFilter(watched, event);
}
